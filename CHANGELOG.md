# Changelog

## 2026.10.21

### Новости и сценарий

- Сбор полного суточного окна с сохранением правок сообщений и истории выпусков.
- Семантический отбор по редактируемому заданию вместо списков брендов и тематических исключений.
- Загрузка связанных статей с датами, происхождением и явными статусами ошибок; исходные тексты сохраняются полностью.
- Настраиваемый состав ведущих и общие правила разговора без обязательной схемы для каждой темы.
- Структурированные реплики, проверка утверждений по источникам и адресные исправления с повторной проверкой.
- Возобновление генерации с атомарных контрольных точек; устаревший кэш пересоздаётся при изменении входных данных или настроек.

### Звук

- Поддержка Silero v5.6 на CPU и отдельного локального пакета модели.
- Единая подготовка произношения для всех команд озвучки с сохранением исходного сценария.
- Исправлена потеря предложения при разбиении длинных реплик и дублирование частей иностранных названий.
- Короткие паузы внутри реплик, тихая музыка без снижения громкости речи и корректное повторное сведение.
- Удалён неработающий провайдер Piper; ошибки выбора провайдера больше не скрываются.

### Эксплуатация

- Прямой llama.cpp с приватным ключом, настройками GGUF, ожиданием готовности и выгрузкой перед синтезом речи.
- Лимиты RAM/swap, ограниченный кэш контекста и явная ошибка при недоступности systemd user manager.
- Защита от повторной публикации, общие блокировки пакетов, безопасные пути и SQLite WAL-backup.
- Изолированные тесты, Ruff, CI и инструкции для разработчиков.

### Проверка

525 тестов и Ruff прошли. Редакторский выпуск за 21 октября: три голоса,
12:34, рендер Silero CPU за 54 секунды; −18,8 LUFS, true peak −1,4 dBFS.
Сценарий подготовлен и проверен Codex, поэтому выпуск не служит подтверждением
качества полностью автоматической генерации.

Локальная проверка фактов остаётся неточной. Дополнительный критик сцен
экспериментален и выключен по умолчанию. Через некоторые прокси загрузка
статей с закреплением IP недоступна; такие ошибки записываются в пакет.
